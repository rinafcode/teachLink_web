# TeachLink Web Project Charter

## Purpose

TeachLink Web provides a trusted place where people can share knowledge, skills,
ideas, and practical information that supports learning and development. The
project exists to make that exchange useful, accessible, and sustainable for its
community.

## Scope

The project includes the web experience, supporting services, documentation, and
community processes required to deliver that purpose. Features and operational
decisions should serve the project's users and preserve the integrity of the
platform.

## Decision Authority

- **Maintainers** are responsible for the health of the codebase, releases,
  security response, and day-to-day technical decisions.
- **Contributors** may propose changes, implement approved work, and participate
  in review according to the contribution guidelines.
- **The community** provides feedback through issues, discussions, and pull
  requests. Community feedback informs decisions but does not replace accountable
  maintainership.

When a decision affects security, privacy, or the availability of the service,
maintainers may act quickly and document the decision afterward.

## How the Charter Changes

Changes to this charter are proposed in a pull request that touches only the
`Governance/` folder. The pull request must explain the reason for the change and
receive maintainer approval before merging. Material changes should be announced
to contributors through the repository's normal communication channels.

## Success

The charter succeeds when contributors can understand the project's purpose,
decision authority, and route for proposing governance changes without relying on
undocumented assumptions.
