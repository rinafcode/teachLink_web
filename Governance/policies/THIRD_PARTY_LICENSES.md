# TeachLink Web Third-Party License Allowlist

This document outlines the approved licenses for third-party content used in the TeachLink Web project.

## Permitted Licenses

The following licenses are permitted for use in third-party content:

- MIT
- Apache 2.0
- BSD-3-Clause
- ISC

## Prohibited Licenses

The following licenses are prohibited for use in third-party content:

- GPL
- AGPL
- LGPL

## Exception Process

If you wish to use a license that is not on the permitted list, you must open an issue in the repository to request an exception. The request will be reviewed by the project maintainers.

## Questions

If you have any questions about this policy, please open an issue in the repository.
