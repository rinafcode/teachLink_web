# Credits and Acknowledgements Policy

This document describes how contributions to TeachLink Web are credited, the format of the credits file, and the update cadence.

## How Contributions Are Credited

All contributors who have made a meaningful contribution to the project will be credited. This includes, but is not limited to:

- Code contributions
- Bug reports
- Documentation
- Design
- Community management

## Credits File Format

A `CREDITS.md` file will be maintained in the root of the project repository. The file will list all contributors and their notable contributions.

## Update Cadence

The `CREDITS.md` file will be updated with each major release of the project.

## Regression Tests

Not applicable for this policy document.
