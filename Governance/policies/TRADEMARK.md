# Trademark Policy

This document outlines the trademark policy for TeachLink Web.

## Protected Marks

The following marks are protected trademarks of the TeachLink Web project:

- TeachLink Web
- The TeachLink Web logo

## Permitted Uses

You are permitted to use the TeachLink Web name and logo to:

- Identify the TeachLink Web project.
- Link to the TeachLink Web website or GitHub repository.

## Request Process for Other Uses

If you would like to use the TeachLink Web name or logo for any other purpose, you must submit a request to the project maintainers. Your request should include:

- A description of the intended use.
- A mockup of how the name or logo will be used.

The project maintainers will review your request and respond within 30 days.
