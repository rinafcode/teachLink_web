# TeachLink Web Attribution Policy

This document outlines the attribution requirements for using third-party content within the TeachLink Web project.

## When Attribution is Required

Attribution is required when using any third-party assets, libraries, or other content that is not owned by TeachLink Web. This includes, but is not limited to:

- Code libraries and frameworks
- Images, icons, and other visual assets
- Sound and video files

## Attribution Format

When attribution is required, it must be provided in a clear and conspicuous manner. The following format should be used:

- **For code libraries:** Include a notice in the `LICENSE` file or in a `THIRD_PARTY_NOTICES.md` file.
- **For visual assets:** Include a credit in the image's metadata or in a caption.
- **For other content:** Include a credit in a location that is easily accessible to the user.

## Third-Party Notice Handling

All third-party notices must be collected and stored in a central location, such as a `THIRD_PARTY_NOTICES.md` file. This file should be regularly updated to reflect any changes in the third-party content being used.

## Questions

If you have any questions about this policy, please open an issue in the repository.
