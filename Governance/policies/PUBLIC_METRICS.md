# Public Metrics Policy

This document outlines the public metrics for TeachLink Web, their update frequency, and data sources.

## Public Metrics

The following metrics are considered public and will be shared with the community:

- **Active Users:** Number of unique users interacting with the platform.
- **Page Views:** Total number of pages viewed.
- **Contribution Growth:** Number of new contributions (e.g., articles, comments, resources).
- **Community Health:** Metrics related to user engagement and satisfaction.

## Update Frequency

Metrics will be updated and published on a **quarterly basis**.

## Data Sources

The data for these metrics will be sourced from our internal analytics tools and databases. Specific sources include:

- Google Analytics
- Internal application database

## Regression Tests

Not applicable for this policy document.
