# TeachLink Web Transparency Report Policy

This document outlines the policy for publishing transparency reports for the TeachLink Web project.

## Report Cadence

Transparency reports will be published on a quarterly basis.

## Metrics Disclosed

The following metrics will be disclosed in each report:

- Number of government requests for user data
- Number of content takedown requests
- Number of security incidents

## Report Publication

Transparency reports will be published in the `/reports` directory of this repository.

## Questions

If you have any questions about this policy, please open an issue in the repository.
