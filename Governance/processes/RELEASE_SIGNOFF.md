# Release Sign-off Process

This document outlines the required sign-offs and gating checks for releasing a new version of TeachLink Web.

## Required Sign-offs

Before any new release, the following individuals or teams must provide their sign-off:

- **Lead Maintainer:** Confirms that all technical requirements have been met.
- **QA Lead:** Verifies that all testing has been completed and passed.
- **Product Manager:** Ensures that the release aligns with the product roadmap.

## Gating Checks

The following checks must be completed before a release can proceed:

1.  **Automated Tests:** All automated tests (unit, integration, and end-to-end) must pass.
2.  **Code Review:** All code included in the release must be reviewed and approved.
3.  **Security Scan:** A security scan must be performed to identify and address any vulnerabilities.
4.  **Documentation:** All new features and changes must be documented.

## Final Authority

The Lead Maintainer has the final authority to approve or reject a release.
