# Third-Party Scripts

This document outlines the governance process for using third-party scripts.

## Allowlist of Hosts

Only scripts from the following hosts are permitted:

- `*.google-analytics.com`
- `*.googletagmanager.com`
- `*.jsdelivr.net`

## CSP Requirement

A Content Security Policy (CSP) must be implemented to restrict the loading of scripts to the allowlist of hosts.

## Review Before Adding Scripts

Any new third-party scripts must be reviewed and approved by the security team before being added to the website.
